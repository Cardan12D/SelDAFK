# Kimetsu UI (аддон для Kimetsu no Yaiba, Forge 1.20.1)

Отдельный мод-надстройка: оригинальный jar **не изменяется**. Добавляет:
- экран персонажа на клавишу **K** (вкладки: Развитие / Дыхание / Характеристики) с анимациями;
- систему очков, статов (Сила → урон, Ловкость → скорость, Выносливость → здоровье), открытие стилей дыхания, пассивки (метка истребителя и др.);
- тултипы мечей Нитирин с редкостью и цветной рамкой.

## Сборка
1. Установите JDK 17.
2. Скачайте Forge MDK 1.20.1 (47.3.0) с files.minecraftforge.net, скопируйте из него в эту папку
   `gradlew`, `gradlew.bat` и папку `gradle/` (нужен только wrapper).
3. `./gradlew build` → готовый мод: `build/libs/knyui-1.0.0.jar`
4. Положите его в `mods/` рядом с KimetsunoYaiba-ver3-forge-1_20_1.jar.
   Для запуска из IDE: `./gradlew runClient` (jar оригинала положите в `libs/` и раскомментируйте строку в build.gradle).

## Тест
Команды (нужен оп): `/knyui points 30`, `/knyui rank 3`, `/knyui level 300`, `/knyui train water.2`, `/knyui reset`.

## Где что менять
- `data/Content.java` — список дыханий, стилей, пассивок (+ строки в `lang/*.json`, иконки в `textures/gui/`).
- `server/StatEffects.java` — формулы статов; `server/ServerLogic.java` — эффекты пассивок.
- `client/Rarity.java` — редкость мечей.
- `client/ui/*Tab.java`, `KnyScreen.java` — внешний вид и анимации; `Draw.java` — примитивы.
- Иконки: `tools/gen_textures.py` генерирует заглушки; замените PNG своими (квадратные, лучше 64x64).

## Что пока НЕ связано с оригинальным модом
- Уровень/ранг/очки хранятся в данных аддона (оригинальные `PlayerLevel` и т.п. не читаются) — управляются командами.
- Открытый стиль пока лишь записывается; чтобы он влиял на атаки, надо связать `unlocked` с вызовом процедур дыхания оригинального мода.

## Сборка без установки (GitHub Actions)
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки (вместе с `.github`).
2. Откройте вкладку **Actions** → **Build mod** → дождитесь зелёной галочки (2–5 минут).
3. Откройте завершённый запуск → внизу **Artifacts** → скачайте `knyui-jar`. Внутри — готовый мод.
Если сборка красная, откройте лог шага **Build** и пришлите текст ошибки.
